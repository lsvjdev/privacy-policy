Privacy Policy.

How Bloxd Fanatic accesses, uses, and protects Discord data to support moderation and safety in the official Bloxd Discord server.

01

Overview

Bloxd Fanatic is a Discord moderation bot used for the official Bloxd Discord server. This policy explains what data the bot may access, how that data is used, how it is protected, and how users can request a review or removal of moderation-related data.

02

Data we access

Bloxd Fanatic may access Discord data required for moderation and safety features, including:

User profiles and IDs
Moderator IDs
Server IDs
Channel IDs
Message IDs
Timestamps
Moderation action details
Report details
Reasons provided by moderators or users
Message content when needed for moderation, reporting, appeals, safety, or abuse prevention
03

Why we use this data

Bloxd Fanatic uses this data for moderation and safety purposes, including:

  • Processing warnings, mutes, unmutes, kicks, bans, and unbans
  • Creating staff-only moderation logs
  • Tracking moderation history
  • Supporting moderation and appeal reviews
  • Handling user reports and reviewing reported messages
  • Preventing abuse of the report system
04

Message content

Bloxd Fanatic may process message content when required for its moderation and safety features.

This may include reported messages, messages reviewed by staff, or messages connected to moderation actions.

05

Data storage & security

Bloxd Fanatic may store limited moderation-related data in a private database. Stored data may include the categories described in Data we access.

Encryption of stored message content

Stored Discord message content is encrypted at the application level using AES-256-GCM before being written to the database. The encryption key is stored separately from the database in environment configuration.

Access to the host, bot files, database, and encryption key is restricted to authorized bot developers only.

06

Data sharing

We do not sell or unnecessarily share user data.

User and moderation data is accessible only to authorized server staff and bot developers as needed for moderation and safety purposes.

07

User opt-out

Users cannot opt out of moderation-related processing while participating in the official Bloxd Discord server because the bot is used to enforce server rules and maintain server safety.

08

Data removal

Users may contact the official Bloxd Discord server staff to request review or removal of moderation-related data where appropriate.

Some data may need to be kept when required for moderation history, appeal review, safety, or abuse prevention.

09

Contact

For questions about this Privacy Policy or Bloxd Fanatic's data usage, contact the staff of the official Bloxd Discord server.
